PRIVACY POLICY

隐私政策

生效及更新日期：2026 年 10 月 26 日

爱目（IAEyes）以本地使用为主，无需注册账号。我们不通过应用自动接收你的休息记录，也不接入广告、分析追踪或开发者运营的云同步服务。

1. 运营主体与适用范围

爱目（IAEyes）由个人开发者 Datie Xu（以下简称“开发者”或“我们”）提供和运营，开发者也是本政策所述个人信息处理责任主体。本政策适用于我们运营的 Apple 平台本地版本（iPhone、iPad 和 Mac），以及本网站与支持联系流程。各设备上的可用版本以对应商店实际发布的信息为准。隐私联系邮箱：itcrown2025@gmail.com。

应用用于工作间歇的休息与图像模拟。画面选择和感受记录不构成健康测量或医疗结论。

2. 应用在设备上保存什么

信息用途与保存位置
画面与使用偏好例如界面语言、翻转节奏、减少动态设置，以及是否使用旅程，用于恢复你选择的体验，保存在本机。
旅程进度你当前所在的级别，用于下次从这一级继续，保存在本机。
购买权益Apple StoreKit 提供商品及签名交易信息，供应用确认是否已解锁完整旅程，并通过 Apple 账户恢复购买。开发者不会收到你的银行卡资料，也不运营购买验证服务器。购买权益可跨设备恢复，旅程进度和记录不跨设备同步。
完成的休息记录例如活动标识、日期、类别、实际计时时长、所用参数、翻面次数、所在级别，结束挑战的答对题数与是否通过，以及可选的感受，用于显示历史记录，保存在本机。
摄像头画面（可选的距离提醒）只有在你开启「距离提醒」后、放松进行时才使用前置摄像头，在设备上估算你和屏幕的距离，离得太近时暂停放松。画面只在内存中逐帧处理，不录像、不保存、不上传；放松结束即关闭摄像头。只保存「是否开启」这一项设置。
摄像头画面（清晰度自查）只在你主动开始「清晰度自查」的远近一项时使用前置摄像头估算距离，处理方式同上：不录像、不保存、不上传，这一项结束即关闭。
清晰度自查记录每次自查的日期、屏幕类型与尺寸、看得清的大致距离范围，以及你在红绿、线条两项里的选择，保存在本机，用于和下次对比。它只描述你在屏幕上看到的样子，不是健康数据。
定时放松设置工作间隔、放松时长和下次提醒时间，保存在本机。手机端到点用系统本地通知提醒，需要你授予通知权限；提醒由设备在本机安排，不经过开发者。

这些本地内容不会自动发送给我们。应用不要求提供姓名、手机号、处方或眼部健康资料；除上述可选的距离提醒和清晰度自查外不使用摄像头，也不使用麦克风、位置、联系人或 HealthKit 数据。你可以随时在应用的「调整」里关闭距离提醒，或在系统设置中撤回摄像头权限。当前版本不包含广告或行为分析 SDK。

3. 保存、清除与系统备份

本地偏好与记录没有自动到期时间，会保留至你清除对应的应用数据。应用无需账号，开发者不通过应用自动接收这些休息记录，无法远程查询或代为删除。

  • 在 iPhone 或 iPad 上，可在“设置 → 通用 → iPhone / iPad 储存空间 → 爱目”中选择“删除 App”来移除应用及其本地数据。“卸载 App”会保留文稿与数据，不能替代删除。
  • 在 Mac 上，仅删除应用本体可能保留本地文件。请通过支持邮箱联系我们，获取与你的版本、安装渠道匹配的数据清理步骤；无需向我们发送记录文件。
  • 设备备份、恢复或迁移可能另行复制或恢复本地内容，具体取决于系统、应用版本配置和你的设置。应用没有自行提供云同步。系统备份受对应平台的政策与控制项管理；若要删除备份副本，还需要在系统或备份服务中分别处理。

4. 你主动联系支持时

发送邮件时，我们会收到你的邮箱、邮件内容和你主动提供的附件、设备或版本信息，用于回复问题、排查故障和处理隐私请求。邮件会由邮件服务商按其服务条款处理。请避免发送证件、病历、眼部照片或其他不必要的敏感资料。

支持资料仅在处理请求及必要的后续记录期间保留；不再需要时会删除。你可以通过上述邮箱申请查询、更正或删除你曾主动提交给我们的支持资料，依法必须保留的内容除外。

如果你选择在 GitHub 提交问题，其内容可能公开，且需遵守 GitHub 的服务规则。隐私问题建议通过邮件联系。

5. 第三方网站与本网站

购买及恢复完整旅程需要与 Apple App Store 服务通信。Apple 按其隐私政策处理 Apple 账户及付款信息。应用不会为此向 Apple 发送休息记录、挑战回答、个人感受或摄像头画面。

应用中的外部参考资料，以及支持页中的第三方链接，由对应网站提供服务。只有在你打开这些链接时，才会访问该第三方网站；请查看其隐私政策。

本网站由 GitHub Pages 托管，不嵌入广告、访问分析脚本、第三方字体或跟踪像素。GitHub 可能为提供托管服务及保障安全处理 IP 地址和请求日志等信息，具体见 GitHub 隐私声明。应用中的本地记录不会随你访问本网站而自动发送给 GitHub。

6. 安全、未成年人及政策更新

本地数据的安全也依赖设备锁屏、系统权限和备份设置。我们只通过你主动发起的支持渠道处理相应资料，不出售本地休息记录或支持资料，也不将其用于广告画像。

我们不以收集儿童个人信息为目的。未成年人可在监护人指导下使用；如你认为儿童通过支持渠道提交了不必要的个人信息，请联系上述邮箱处理。

政策更新会在本页注明日期。若未来的数据用途、上传行为或第三方服务发生实质变化，我们会在相应功能启用前更新说明，并在适用时征求你的同意。

当前版本无广告。若未来引入广告或赞助内容，会在启用前说明实际服务商、涉及的信息及用途，更新本政策和商店隐私资料，并依法及按平台要求取得必要授权、提供相应控制。本政策不构成对未来数据收集或广告追踪的预先同意。

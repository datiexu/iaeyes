PRIVACY POLICY

隐私政策

生效及更新日期：2026 年 10 月 27 日

爱眼睛（IAEyes）以本地使用为主，无需注册账号。我们不通过应用自动接收你的休息记录，当前无广告或分析追踪。提供 iCloud 设置的版本中，旅程与记录同步分别选择、默认均关闭；开启后，相应数据发送至 Apple 的私人 iCloud 存储，不发送至开发者运营的服务器。

版本范围：TestFlight 1.0.0 build 18 的应用记录仅存本机，没有 iCloud 同步开关。下列可选同步条款仅适用于后续显示 iCloud 控制项的版本，网页更新不会让旧版开始同步。

1. 运营主体与适用范围

爱眼睛（IAEyes）由个人开发者 Datie Xu（以下简称“开发者”或“我们”）提供和运营，开发者也是本政策所述个人信息处理责任主体。本政策适用于我们运营的 Apple 平台本地版本（iPhone、iPad 和 Mac），以及本网站与支持联系流程。各设备上的可用版本以对应商店实际发布的信息为准。隐私联系邮箱：itcrown2025@gmail.com。

应用用于工作间歇的休息与图像模拟。画面选择和感受记录不构成健康测量或医疗结论。

2. 应用在设备上保存什么

信息用途与保存位置
画面与使用偏好例如界面语言、翻转节奏、减少动态设置，以及是否使用旅程，用于恢复你选择的体验，保存在本机。
旅程进度当前选择的级别、已解锁的最高级别、该级累计有效时间及终局完成状态，保存在本机。已获得进度的快照可按下文自愿同步；当前选择的回练级别和个人显示校准不参与同步。
购买权益Apple StoreKit 提供商品及签名交易信息，供应用确认是否已解锁完整旅程，并通过 Apple 账户恢复购买。开发者不会收到你的银行卡资料，也不运营购买验证服务器。购买权益可跨设备恢复，与可选的 iCloud 数据同步开关独立；购买或恢复不会开启同步或授予未经获得的进度。
完成的休息记录例如活动标识、日期、类别、实际计时时长、所用参数、翻面次数、所在级别，结束挑战的答对题数与是否通过，以及可选的感受，用于显示历史记录，保存在本机。另行开启记录同步后，完成记录快照（包括可选感受及练习中的逐题回答）也可能上传。云端最多保留最新 500 条且快照不超过 10 MB；此云端限额不会删除较早的本机记录。
摄像头画面（可选的距离提醒）只有在你开启「距离提醒」后、放松进行时才使用前置摄像头，在设备上估算你和屏幕的距离，离得太近时暂停放松。画面只在内存中逐帧处理，不录像、不保存、不上传；放松结束即关闭摄像头。只保存「是否开启」这一项设置。
摄像头画面（清晰度自查）只在你主动开始「清晰度自查」的远近一项时使用前置摄像头估算距离，处理方式同上：不录像、不保存、不上传，这一项结束即关闭。
清晰度自查记录每次自查的日期、屏幕类型与尺寸、辨认出的最小图形、据此确定的个人起始大小、看得清的大致距离范围，以及你在红绿、线条两项里的选择，保存在本机，用于和下次对比。它描述主观的屏幕观察，不是医学评估。自查结果、个人起始大小和观看距离设置均不参与应用的 iCloud 同步。
可选的字母大小反馈旅程结束时选择大、中、小，会将活动标识、日期、级别、基准大小和所选档位单独保存在本机，最多 500 条，也可跳过。此反馈不会改变起始大小、级别或挑战成绩，不参与应用的 iCloud 同步。
定时放松设置工作间隔、放松时长和下次提醒时间，保存在本机。手机端到点用系统本地通知提醒，需要你授予通知权限；提醒由设备在本机安排，不经过开发者。

这些本地内容不会自动发送给我们。应用不要求提供姓名、手机号、处方或眼部健康资料；除上述可选的距离提醒和清晰度自查外不使用摄像头，也不使用麦克风、位置、联系人或 HealthKit 数据。你可以随时在应用的「调整」里关闭距离提醒，或在系统设置中撤回摄像头权限。当前版本不包含广告或行为分析 SDK。

勋章图片（提供此功能的版本）：勋章在本机从已获得的旅程进度和通过的挑战派生。保存或分享时生成 PNG，仅含勋章、级别、阶段和爱眼睛标识文字，不含日期、分数、感受或详细记录。iPhone/iPad 保存时仅请求添加照片权限，不读取相册；Mac 由你选择保存位置。分享打开系统菜单，仅向你选择的目标传送图片。相册、所选目录或接收服务可能按其设置与条款同步、处理导出的副本。删除应用或云端记录不会删除已导出的图片，需在目标应用或目录中另行删除；应用临时导出文件在操作结束后清除。

3. 可选 iCloud 同步、保存、清除与系统备份

由你选择：每台设备的旅程同步和详细记录同步均分别默认关闭，只有在应用 iCloud 面板中主动开启后才启用。开启某项即允许其已有本机数据与后续变更上传至你的私人 CloudKit 数据库，并在同一 iCloud 账户、同样开启该项的其他设备上下载。无需另建爱眼睛账号；iCloud 账户可能与购买使用的 App Store 账户不同。

发送的数据：旅程同步仅发送旅程格式版本、已解锁最高级别、该级有效毫秒数及终局完成标记，不发送详细记录。记录同步发送上述完成记录，以及用于合并冲突的编辑序号和随机生成的应用安装标识。自查结果、个人起始大小、摄像头画面、距离设置、语言及定时偏好均不参与应用同步。无论是否开启同步，摄像头画面始终不录像、不保存、不上传。

用途与服务商：Apple 按其隐私政策与 iCloud 条款提供 iCloud/CloudKit 跨设备存储及传送，可能为此处理账户、设备、网络及服务信息；存储地点及跨境处理取决于 Apple 服务与账户设置。开发者不运营应用同步服务器，不通过开发者管理界面访问你的私人 CloudKit 数据库，不将这些数据用于广告或追踪。我们不承诺超出 Apple 对该服务实际提供的端到端加密保护。

合并与可用性：保留已获得的最高级别；同一级别取较大的已保存时间，不把不同设备的时间相加，因此并行或离线练习可能不会全部累计。时间不转入下一级，同步不能代替该级时间门槛或已通过的挑战。记录按标识去重；感受的并发编辑按确定的编辑序号规则解决，合并后可以再次修改。应用打开且空闲时尝试同步，离线失败后稍后重试；需要可用的 iCloud 账户、网络及 iCloud 空间，不保证可替代备份。应用检测到 iCloud 账户变化或退出时，会关闭两个开关并保留本机副本；在另一账户重新开启前，请检查本机数据。

关闭与删除：在一台设备关闭某项会停止该设备后续的应用同步，保留本机与云端副本；已发出的请求可能完成，其他已开启的设备仍可同步。应用分别提供「删除云端进度」「删除云端记录」及确认步骤：删除相应云端数据内容、关闭本设备该项同步，保留本机副本与一个最小删除标记。其他设备在下次同步时关闭该项。日后重新开启是一次新的选择，可能再次上传保留的本机数据。设备及系统备份独立，需分别管理；开发者无法代你远程读取或删除私人 iCloud 内容。

本地偏好与记录没有自动到期时间，会保留至你清除对应的应用数据。应用无需账号，开发者不通过应用自动接收这些休息记录，无法远程查询或代为删除。

  • 在 iPhone 或 iPad 上，可在“设置 → 通用 → iPhone / iPad 储存空间 → 爱眼睛”中选择“删除 App”来移除应用及其本地数据。“卸载 App”会保留文稿与数据，不能替代删除。
  • 在 Mac 上，仅删除应用本体可能保留本地文件。请通过支持邮箱联系我们，获取与你的版本、安装渠道匹配的数据清理步骤；无需向我们发送记录文件。
  • 设备备份、恢复或迁移可能另行复制或恢复本地内容，具体取决于系统、应用版本配置和你的设置。备份与上述可选应用 iCloud 同步独立。系统备份受对应平台的政策与控制项管理；若要删除备份副本，还需要在系统或备份服务中分别处理。

4. 你主动联系支持时

发送邮件时，我们会收到你的邮箱、邮件内容和你主动提供的附件、设备或版本信息，用于回复问题、排查故障和处理隐私请求。邮件会由邮件服务商按其服务条款处理。请避免发送证件、病历、眼部照片或其他不必要的敏感资料。

支持资料仅在处理请求及必要的后续记录期间保留；不再需要时会删除。你可以通过上述邮箱申请查询、更正或删除你曾主动提交给我们的支持资料，依法必须保留的内容除外。

如果你选择在 GitHub 提交问题，其内容可能公开，且需遵守 GitHub 的服务规则。隐私问题建议通过邮件联系。

5. 第三方网站与本网站

购买及恢复完整旅程需要与 Apple App Store 服务通信。Apple 按其隐私政策处理 Apple 账户及付款信息。应用不会为此向 Apple 发送休息记录、挑战回答、个人感受或摄像头画面。

应用中的外部参考资料，以及支持页中的第三方链接，由对应网站提供服务。只有在你打开这些链接时，才会访问该第三方网站；请查看其隐私政策。

本网站由 GitHub Pages 托管，不嵌入广告、访问分析脚本、第三方字体或跟踪像素。GitHub 可能为提供托管服务及保障安全处理 IP 地址和请求日志等信息，具体见 GitHub 隐私声明。应用中的本地记录不会随你访问本网站而自动发送给 GitHub。

6. 安全、未成年人及政策更新

本机及同步数据的安全也依赖设备锁屏、iCloud 账户安全、系统权限和备份设置。我们只通过你主动发起的支持渠道处理相应资料，不出售本地休息记录或支持资料，也不将其用于广告画像。

我们不以收集儿童个人信息为目的。未成年人可在监护人指导下使用；如你认为儿童通过支持渠道提交了不必要的个人信息，请联系上述邮箱处理。

政策更新会在本页注明日期。若未来的数据用途、上传行为或第三方服务发生实质变化，我们会在相应功能启用前更新说明，并在适用时征求你的同意。

当前版本无广告。若未来引入广告或赞助内容，会在启用前说明实际服务商、涉及的信息及用途，更新本政策和商店隐私资料，并依法及按平台要求取得必要授权、提供相应控制。本政策不构成对未来数据收集或广告追踪的预先同意。
